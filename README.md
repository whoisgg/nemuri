# Nemuri

Prototipo del sitio de Nemuri Care: home, catálogo y ficha de producto en un solo `index.html`, sin build.

- `index.html` — markup, estilos y script.
- `img/` — fotos de home y de producto.
- `video/` — video de la sección Novedades y su póster.

Es un sitio estático: Vercel lo publica tal cual, sin framework ni comando de build. Para verlo en local basta con servir la carpeta, por ejemplo `npx serve .`.
